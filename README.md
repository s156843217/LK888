# 太平洋房屋・林口捷運加盟店工作平台

純前端網頁，直接開啟 `index.html` 即可使用，無需安裝套件或建置。

## 目前功能

- 課程指令 19 則、分類搜尋、複製與本機編輯。
- 月曆（週一開始）與橫式值班表、特殊人員條件、預排及鎖定。
- 列印班表。

指令修改及排班只儲存在操作人的瀏覽器。正式管理員登入、共用指令儲存、國定假日與補班日自動資料、圖片下載尚未完成。假日可先手動設定。

## 部署

GitHub Pages 使用 `main` 分支根目錄。更新前檢查首頁、指令庫與排班功能，再提交並推送；確認 Pages 建置成功且線上內容已更新。

本機暫存不會隨部署上傳，也不會從本機檔案網址自動搬到正式網址。
