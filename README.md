# 太平洋房屋・林口捷運加盟店工作平台

純前端網頁，直接開啟 `index.html` 即可使用，無需安裝套件或建置。

## 目前功能

- 課程指令 22 則、分類搜尋與複製；網頁不提供編輯功能。
- 月曆（週一開始）與橫式值班表、特殊人員條件、預排及鎖定。
- 列印班表。

目前版本為 v1.0.5。指令由網站檔案統一維護，修改 `prompts-data.js` 並部署後，所有人重新載入即可看到新版。舊的本機指令修改不再套用。

排班仍只儲存在操作人的瀏覽器。國定假日與補班日自動資料、圖片下載尚未完成。假日可先手動設定。

## 部署

GitHub Pages 使用 `main` 分支根目錄。更新前檢查首頁、指令庫與排班功能，再提交並推送；確認 Pages 建置成功且線上內容已更新。

本機暫存不會隨部署上傳，也不會從本機檔案網址自動搬到正式網址。
